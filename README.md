# Alphabet-Uniform Sunflower Capacity — P001C

Independent CHILD repository of the [Sunflower Structures Programme](https://github.com/jfairfaxball-348/sunflower-structures-programme). The permanent headline is Erdős–Rado for every fixed r≥3. **P001C targets three petals only.** Parent S004 selected this direction, parent S005 performs bootstrap only, and first mathematics P001C-S001 is future-only in a **separate ChatGPT Project** named *Alphabet-Uniform Sunflower Capacity*.

For D≥3,n≥1 and A⊆[D]^n of distinct vectors, three distinct vectors are a sunflower if every coordinate is either all equal or all three different. U(D,n) is the largest sunflower-free |A|. Published Naslund–Sawin 2017 Thm 5: U(D,n)≤(3(D−1)^(2/3)/2^(2/3))^n. The unproved near-term challenge is U(D,n)≤(K D^(2/3−δ))^n for universal K,δ>0, all D,n. Such an exponent improvement by itself **would not prove** Erdős–Rado; a D-INDEPENDENT C^n bound would transfer to the ordinary three-petal conjecture via ASU 2013 Thm 2.6 (source report). None of these improvements has been obtained by P001C.
